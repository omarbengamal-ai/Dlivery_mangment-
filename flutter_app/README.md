# Driver Custody Flutter app

This is a contained Flutter desktop application added under the `flutter_app/` directory.

Run:

1. Install Flutter SDK (stable channel) and enable desktop support for your OS.
2. In this directory run `flutter pub get`.
3. Run `flutter run -d windows` (or `-d macos` / `-d linux`) or `flutter run -d windows --release`.

This app demonstrates the Driver Financial Custody section with mock data and is structured so a backend service can be swapped in later.
